# Test report

Write a test report for the Concrete to Framer tool. The tests exist to improve that tool.

Work one section at a time. Finish it before the next section. Do not repeat a fact already written.

Each pass uses this order:

1. Goal, and whether that goal was met.
2. What was there.
3. What changed, and why it changed.

The report answers three questions: why the tests were done, whether they met the goal, and what was done. Follow the general trend and the large changes. A small script or data tweak is one sentence: "The following data was removed because ..."

Write the prose with the humanizer skill. Keep every number, date, and path the notes support. Do not add a result the notes do not contain.
