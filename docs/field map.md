## Capture fields

`simplify` drops a `display:none` subtree and an effect-free wrapper before a digest is written (`scripts/digest/generate.ts:283`, `scripts/digest/generate.ts:288`). A row that says yes means a kept node. An omitted node leaves `sourceId` and reason `display-none` (`scripts/digest/generate.ts:276`). A folded wrapper leaves `sourceId`, reason `wrapper-without-effect`, `childSourceIds`, and `href` when the wrapper is an anchor (`scripts/digest/generate.ts:290`). Those records leave out tag, box, classes, and styles.

## Absent for the builder

These are values the builder needs for layout, text, links, alt text, or icons, and they are absent from every file `BUILDER.md` tells it to open.

- Outline width, style, and colour. `traitsOf` reads `outlineStyle` and `outlineWidth` and stores the flag `outline` (`scripts/generic-extractor/browser.js:33`). `STYLE_PROPS` does not store the values (`scripts/generic-extractor/browser.js:7`).
- `mix-blend-mode`. The trait `blend` is stored (`scripts/generic-extractor/browser.js:44`). The computed value is not in `STYLE_PROPS`.
- Font family, size, weight, line height, letter spacing, and text transform of a painting `::before` or `::after`. The capture stores them on the pseudo (`scripts/generic-extractor/browser.js:55`). `measurePseudo` drops them (`scripts/digest/generate.ts:911`). The content string and the colour remain. The font name is absent, so a glyph icon has no font to draw with.
- `aria-label` and the `title` attribute. They are read only while dismissing consent (`scripts/generic-extractor/browser.js:290`) and are not written on the node.
- Password field values. The capture stores `""` (`scripts/generic-extractor/browser.js:110`).
- Text, boxes, and styles of `head`, `script`, `style`, `noscript`, `template`, `link`, and `meta`. Those tags are skipped (`scripts/generic-extractor/browser.js:5`). The `excluded` list from `collect` is not written (`scripts/generic-extractor/extract.ts:98`).
- Inner contents of iframe, embed, canvas, and video, and of a shadow root. The boundary kind and child count are kept. Markup is written for `svg` only (`scripts/generic-extractor/browser.js:116`).
- Href of an omitted anchor when the destination is empty, `javascript:`, or unclassified. `linkRecords` skips that anchor (`scripts/digest/generate.ts:725`). `provenance.omitted` stores the id and the reason `display-none` (`scripts/digest/generate.ts:276`). The href is absent from that record.
- Whether an omitted or folded anchor was an inline run. The builder is told to record that (`.cursor/SKILLS/BUILDER.md:38`). `provenance.omitted` and `provenance.folded` store no `display` (`scripts/digest/generate.ts:269`).
- Font availability. The builder reports a missing font (`.cursor/SKILLS/BUILDER.md:27`). The capture stores no `@font-face` availability. The digest object has no `fonts` key (`scripts/digest/generate.ts:224`).
