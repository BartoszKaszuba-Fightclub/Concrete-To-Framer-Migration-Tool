# Classification

Four levels. The commands stay in `.cursor/SKILLS`.

- **Atom.** One text node, one image, or one link. An atom is unlabeled.
- **Molecule.** Repeated siblings with the same tag and the same ordered child tags. On this fixture, the two article cards.
- **Organism.** A section candidate: header, main, or footer.
- **Template.** The page that orders the organisms.

Commands: `.cursor/SKILLS/ORCHESTRATION.md`, `.cursor/SKILLS/COLLECTOR.md`, `.cursor/SKILLS/SECTIONS.md`, and `.cursor/SKILLS/BUILDER.md`.
